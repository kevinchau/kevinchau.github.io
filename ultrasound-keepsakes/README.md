# Ultrasound keepsakes

Public viewer: https://kevinchau.github.io/ultrasound-keepsakes/

Two artistic 3D busts made from generated illustrations using local TripoSR inference. They are not measured anatomy or a prediction of appearance at one year.

See [METHODS.md](METHODS.md), the input prompts, and output/pipeline-report.json for provenance and limits. Original portrait PNGs and GLB/OBJ/STL files are downloadable.

The original gallery remains at https://stayhumblehkger.github.io/ultrasound-collection/
